1. Extract this zip.
2. Open the extracted folder: GameForge-AI_GitHub_Upload_Ready.
3. Upload the CONTENTS of this folder to your GitHub repository using Add file > Upload files.

4. Commit the upload.
5. The real Electron app is inside the /app folder.

Safe checks already done:
