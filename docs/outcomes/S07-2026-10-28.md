## Implemented in ForgeCore, not only a development helper

- New typed `search_local_blender_assets` / `SearchLocalBlenderAssets` tool, parser, security policy, executor, JSON grammar and bounded deterministic desktop prompt route. Example: `Search local Blender assets for barrel.` Searches run offline without inference/provider fallback, Blender/Unity launch, source/index writes or imports.
- Filters: words, recipe, prop/character role, required rig, minimum/maximum height in millimetres, maximum triangles and 1–20 results. Existing imported skins have zero source motion clips; finding a rig does not imply compatible animation/gameplay.
- Bounded directory scan (128 entries), bounded metadata/files and verification charge (512 MiB), cancellation, explicit truncation/rejection counts. Each returned match re-verifies the immutable entry, fixed bundled recipe, request, editable `.blend`, GLB, textures, preview, metrics and optional rig. Reparse points/paths/scripts and approval fields are rejected. Output dimensions are Blender Z-up source metres, not falsely reported as target Unity measurements.
- Results are **unreviewed local candidates**, with visual/rights/placement approval false. No existing reviewed-vault or live human-review gate is relaxed; no local candidate is silently promoted or placed. No new recipe, character art, map, package, model or paid service was added.
