# S03 — animation lab foundation

Started 27 October 2026 (Australia/Sydney). **In progress; not full stage acceptance.**

## Implementation scope

- Preserve the S02 original Blender source/GLB and previous scenes. Generate eight original, parameterized Unity `.anim` clips against its existing Generic named skeleton: Idle, Walk, Run, Aim, Fire, Reload, Hit and Death. These are not downloaded mocap, Blender Actions or output from an arbitrary learned motion model.
- Save editable curves and a real Unity Animator controller. A one-dimensional speed blend tree selects idle/walk/run; exclusive action states handle aim/fire/reload/hit/death. Runtime code owns root translation/turning; `applyRootMotion=false`. Curves animate the actual skinned skeleton, not the old rigid-part placeholders.
- A separate auto-demonstrating lab provides pause, manual fire/reload/hit/death and restart buttons. A simple original box rifle and visible training projectiles are timing aids, not S04/S05-quality art or S06 tactical combat.
- Keep fire/reload exclusive, commit ammo only at completed reload, cancel unfinished reload on damage/death, freeze simulation/Animator/projectiles on pause and emit a projectile from the evaluated muzzle after animation evaluation. Death stays terminal until explicit lab reset.
- The bounded offline prompt is `Create an animated rigged mannequin in Blender. Name it training-motion.` ForgeCore creates the base in Blender, then generates the clips in Unity through separately scoped steps. The existing non-animated barrel/mannequin routes remain unchanged.
- New typed operation `prepare_character_animation` accepts only the exact imported GLB/hash, bounded asset-set identifier, fresh scene and preview. Its derived clip folder, scene, metadata, PNG and preview sidecar cannot already exist. Original GLB/provenance/metadata remain protected. Execution requires the exact installed bridge and template kit. No arbitrary script, external API or paid generation is introduced.
- Hash-retained diagnostic evidence covers the source identity, clips/controller and Unity metadata, report, scene and preview. It always records `stageComplete=false`, `visualReviewed=false`, `rightsReviewed=false`.
