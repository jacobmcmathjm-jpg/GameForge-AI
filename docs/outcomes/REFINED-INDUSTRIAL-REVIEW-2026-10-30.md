# Refined industrial source and Unity review — 30 October 2026

This is a review/source-reuse package, **not a new playable level or human-approved art library**. ForgeCore's production executor generated the five original procedural props in installed Blender using the versioned recipes developed in this session. These are bounded recipe families, not general prompt-to-any-model AI or concept-image realism.

## What is included

Five immutable current source bundles (barrel, braced crate, concrete barrier, welded fence, sealed container), with editable `.blend`, exact Python/request, three GLBs, 1K material maps, measurements and source preview. The `.forgecore/blender-library` subtree preserves original entry/content hashes and exact cache references. It contains no visual/rights approval or promotion records. Do not execute source scripts just to inspect a preview.

`unity-previews` contains real 1280×720 four-view Unity images and their exact provenance. `imported` contains individually imported main GLBs and original sidecars as evidence; these copies are not a portable Unity project or prepared prefabs. `evidence` contains production creation, cache reuse, import, three-LOD/collider preparation, structural inspection and preview receipts. `proposals` are exact technical-review proposals for the original D-drive project, **not decisions**; they are not valid for another destination without fresh inspection/preview metadata.

All five current source cache reuses returned the identical bundle hashes. Real Unity technical fixtures verified three LODs, measured metre bounds, finite UVs, materials and one conservative solid-box collider per prepared prop. Four-view generic asset inspection covers the main GLB, not the prepared collider/LOD hierarchy. The recipe's source and the separate Unity views should both be reviewed.

## Remaining decisions and integration

The sources and targets remain unaccepted. The app's source and target review dialogs now show verified previews and require an explicit acknowledgement; no human acceptance was invented during testing. Source visual/rights reviews and promotion remain separate from target review, placement, runtime collision/navigation, performance, balance and final art acceptance.

The read-only refined layout uses ten placements in the same small authored courtyard, not a bigger map. It moves the proposed second crate clear of a container and the proposed first container clear of the divider. Its conservative nominal grid audit checks all three objective-route segments, including thin-obstacle swept edges. This is **not Unity physics/NavMesh or runtime proof**. Existing gameplay scenes/builds were not rewritten. Automatic placement remains unavailable/unapproved; missing real reviews blocked the asset-set import with zero set-import folders written.

## Bounded offline prompts in the updated app

`Create a refined wooden crate in Blender. Name it review-crate.` creates the new fixed crate recipe. The corresponding barrel, concrete barrier, industrial fence and shipping container names are supported. Old prompts without `refined` keep the old versioned sources.

`Plan refined industrial assets for refined-yard.` is read-only. It returns the exact current source candidates, live review proposals, explicit missing gates and nominal placement audit. It does not approve, import or place anything.

For an exact selected bundle: `Review local Blender asset <64-character bundle hash> visually.` Then independently review its rights using `Review local Blender asset <same hash> rights.` Rejection is valid; do not accept a source simply to unblock work. `Check local Blender asset <hash>.` explains promotion eligibility; `Promote local Blender asset <hash>.` still requires both real current source reviews. A new destination always needs its own technical preparation and target review. Keep the source recipe IDs/hash identities intact.

The library needs installed Blender 5.2 for creation, and Unity for target work. No paid service, external generation API, model key or new online asset download was used. This package does not give ForgeCore arbitrary genre builders or guarantee realistic/AA quality.

Prior unrefined bundles, old game builds, guard motion, death support, muzzle flash, accepted gunshot and exact user-approved hard-floor recordings remain unchanged.
