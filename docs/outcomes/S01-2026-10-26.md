## Provisional diagnostic/acceptance contract

Defined before the new instrumented player runs, for this workstation prototype baseline only:

- Existing p95 CPU/GPU frame budgets remain 33.334 ms; allocated-memory budget remains 4 GiB.
- Maximum interactive interval must be **at most 100 ms**, for both Unity unscaled delta and an independent monotonic Stopwatch Update-to-Update clock. Any interval above 100 ms fails acceptance even if p95 passes. Counts above 33.334, 50 and 100 ms are retained.
- Engine-startup-to-measurement boundary must be **at most 15 seconds**. Report Awake, theme creation, profile setup, actual warmup duration and maximum warmup frame separately. Loading/warmup is not silently folded into steady gameplay, nor called smooth merely because it is outside p95.
- Preserve up to 32 first long-frame contexts with frame index, elapsed time, both clocks, focus state and interval GC counts; preserve total counts even if the sample list fills. Record focus/pause event counts and the actual background-run policy without silently changing it.
- One-second warmup transitions at an observed frame boundary. Its boundary-spanning interval is retained in warmup diagnostics; subsequent complete intervals are measured. A later hitch must remain in the interactive maximum/counts and fail the gate.
- Profile request/result/evidence schema becomes 3 and kit becomes 0.16.34. Old evidence/builds remain untouched; new profile acceptance requires fresh matching instrumentation. Hash/identity and failure/timeout checks remain in force.

New source: `PlayerFrameDiagnostics` host contract, `PrototypeFrameDiagnostics` runtime tracker, host tampering/rare-hitch regressions and two deterministic Unity phase/bounded-record tests. Synthetic tests prove detection and gating; they do not diagnose the old real event.

The old 1,727.84 ms event **did not reproduce**, either in the three unchanged-build repeats or these instrumented runs. New phase boundaries change how startup is classified, so this is not a controlled before/after performance improvement or a proven fix. Do not infer shader compilation, GC, focus loss or developer-tool contention as the historical cause.
