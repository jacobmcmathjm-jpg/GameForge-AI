# S10 — connected industrial level candidate

Started 16 November 2026. Extends ForgeCore's reusable industrial FPS route, not a one-off edit to the accepted courtyard. User accepts the glove/uniform pass provisionally and requests a larger service-yard → warehouse → control-room mission. **Single-floor bounded prototype, not arbitrary maps, stairs, finished indie/AA art, another genre or final S10 acceptance.**

## Implemented contract

An explicit typed `layout_profile=industrial_connected_v1` is allowed only for `create_industrial_mission` and cannot combine with retro. Plain app prompt: **Create a connected industrial level named connected-yard.** The eleven-action offline planner chooses that exact profile; mismatched layout observations stop follow-up, not substitute a courtyard. Other prompts and prototype genres remain separate existing capabilities.

Bridge **0.17.23**, kit **0.16.104**. Exact known-hash upgrades protect previous .22 bridge and .99–.103 kits with backups; unknown changes are never overwritten. Existing generated scenes, source reviews and exported games are retained.

A 64×64, one-metre bounded navigation envelope supports the original 32m service yard plus adjacent warehouse and control-room areas. It rejects unsupported floor/void cells as well as solid obstacles. This is three connected accessible ground-floor zones, not a uniformly walkable 64m square, open world or multi-storey navigation.

Power opens the loading gate. Two warehouse guards gate manifest retrieval. The manifest opens the control-room door, whose guard gates final transmission/extraction. Three guards and three ordered interactions are retained. New architecture provides actual floors, ceilings, walls, console/cargo cover, waypoint signs and three unshadowed practical lights. Static added architecture is batched by material; independent solid colliders and movable door leaves remain. Existing character/glove/rifle meshes, action clips, warm flash, gunshots and recorded footsteps are reused.

Old courtyard art batches are derived in the fresh output folder to remove the former north backdrop; source assets are not modified. Parent art/combat reports describe the **intermediate original courtyard prepass**, not final expanded layout dimensions/resource measurements. The new connected report independently audits final collider reachability, gate isolation, route length, resources and combat-anchor preservation. A later actual runtime preview represents the final level; the inherited before/after sheets do not.

## Persistence and testing boundaries

Connected checkpoints require their own matching profile and bounded coordinates (-15..47 on x/z, y 0..3). Legacy courtyard saves still require their original profile and ±15 bounds. Normal connected saves use a distinct persistent folder; diagnostic checks use owned test scopes only. Bad-profile or blocked loads leave current state unchanged. A synchronous hypothetical door-collision check restores the prior collider state before accepting/rejecting a load; successful restore then synchronizes the saved mission/gates.

Legacy courtyard tests retain their original assertions and select courtyard-only fixtures; five additional connected PlayMode tests cover doors, floor/void rejection, route bounds, reset/restore and far-control-room saves. The new actual player probe must visit all three zones, traverse >110m, validate gate states and round-trip a warehouse checkpoint beyond the old area using actual controller/projectile play, without direct damage or player teleport.
