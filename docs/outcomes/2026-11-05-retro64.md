# Original N64-inspired courtyard profile — 5 November 2026

User direction: original Nintendo 64-era GoldenEye-style presentation, not the remaster. Implement an original low-poly option with modern smooth controls and the existing audio. No game/ROM/model/texture/music extraction, licensed remake, exact hardware emulation or universal game generator is claimed.

## Reusable contract

`Create a retro industrial courtyard named retro-yard.` selects `style_family=retro_64` on the existing typed `create_industrial_mission` operation. `n64-style` and `GoldenEye 007-style` are aliases for this same original profile, not permission to acquire game assets. Unnamed retro requests use `retro-courtyard`. Omitted style preserves the detailed/default route and its original seven arguments. Unsupported mission styles and mismatched prior style observations stop instead of silently substituting or exporting.

Kit 0.16.92 / bridge 0.17.22 use exact-hash protected upgrades from 0.16.90 / 0.17.21 through the retained 0.16.91 candidate. Original Blender recipes, previous games and scenes are preserved. The profile builds new low-poly Unity mesh derivatives from the retained original Blender rig; it does **not** create a newly reviewed Blender source model or promote unreviewed source-vault assets.

The profile generates eight original 32–128px, 32-level-per-channel painted maps, vertex-lit materials, a new skinned guard and forearm mesh, and a simple rifle with the existing animated magazine transform. Existing action clips, grips, sight/muzzle sockets, movement, audio and collision count must remain unchanged. The lowest original template-prop meshes become the only active LOD, modern trim/detail batches and reflection probes are disabled, and simple flat ambient lighting/fog replaces PBR reflections. Native rendering and smooth controls are retained; this is not 320×240 hardware emulation.

The two original cover overlaps are corrected **only in the opt-in candidate**: supplies-2 moves from Z=-1 to -5; containers-1 from Z=0 to -2. Independent nominal planning and actual collider/route checks must pass. Fences retain their solid box proxies; this does not implement wire collision or an expanded map.

Strict report gates reject over-budget geometry/maps, changed sockets/audio/clips, added colliders, obstructed routes, nominal overlap and invented visual/rights/library approvals. The four existing detailed-style-specific test fixtures explicitly select retained non-retro missions; their thresholds are not relaxed. Four additional rendered tests cover the retro geometry/rig/texture/layout contract.
