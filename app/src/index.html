What GameForge generates right now
Environment Walkthrough / Project Shell — A Blueprint-only Unreal project that opens with terrain and sky. You can walk around, but there is no player HUD, no weapons, no health, no enemies, and no gameplay systems. The folders, config files, and documentation are correct and ready for you to build in Unreal Editor.

Playable Templates — When a matching template is installed, GameForge copies it and classifies the output automatically using 8 honest stages: movement_base (player + map), fps_asset_base (weapon assets detected — not confirmed active), fps_weapon_base (weapon + config confirmed), zombie_asset_base (enemy assets detected — not confirmed active), zombie_shooter_base (enemies + weapons confirmed), full_playable_template (all systems + config confirmed). Asset files alone do not prove systems are active in Play mode — config evidence is required. Set status: "stable" in template_manifest.json to activate.

See docs/Template_Install_Guide.md for instructions.

Generation Options

1. Project Shell / Environment Walkthrough
Safe fallback — used automatically when no template is installed. Opens in Unreal with terrain and sky. Blueprint-only, no plugin errors. No gameplay systems. GameForge handled this automatically.
2. Playable Movement Template (movement_base)
Auto-detected when player blueprint + map found. Player/camera movement confirmed. No weapon, enemies, HUD, or health yet. GameForge classifies this automatically. Not a full game.
3. FPS Asset Base (fps_asset_base)
Weapon and HUD asset files detected in Content/. Active gameplay not confirmed — asset files alone do not prove weapons fire in Play mode. No config/GameMode evidence found. Open in Unreal Editor and press Play to verify.
4. FPS Weapon Template (fps_weapon_base)
Weapon/HUD assets confirmed alongside config evidence (custom GameMode in DefaultGame.ini). Movement + weapon + HUD active. No enemies or objective loop yet.
5. Zombie Asset Base (zombie_asset_base)
Enemy asset files detected in Content/. Active enemy AI not confirmed — asset files alone do not prove enemies spawn in Play mode. No config/GameMode evidence found. Open in Unreal Editor and press Play to verify.
6. Zombie Shooter Base (zombie_shooter_base)
Enemy assets confirmed alongside weapon assets. Movement, weapons, and enemies detected. Full HUD and objective loop may still need verification. Custom GameMode in config recommended.
7. Playable Template Project (full_playable_template)
All systems confirmed via strict asset detection and custom GameMode in Config/DefaultGame.ini. Player, weapons, enemies, HUD all present and config-verified. Press Play immediately in Unreal Editor.
8. Packaged Build (future)
Compiled Windows .exe — the final deliverable. Requires a user-controlled export step in Unreal Editor (File > Package Project). Manual action required only at this stage.
