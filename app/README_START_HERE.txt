GAMEFORGE AI ENGINE v3.3.1 — START HERE

This is the Installer Pro Pack.

BEST LONG-TERM OPTION:
1. Extract this zip once.
2. Open the extracted folder.
3. Double-click INSTALL_GAMEFORGE_TO_DESKTOP.bat.
4. When it finishes, use the desktop shortcut:
   GameForge AI Engine

The installer will:
- Copy GameForge to your AppData app folder
- Install dependencies there
- Run a health check
- Create Desktop shortcut
- Create Start Menu shortcut
- Offer to launch GameForge

MAINTENANCE TOOLS:
- REPAIR_GAMEFORGE_INSTALL.bat
- UPDATE_INSTALLED_GAMEFORGE.bat
- RESET_GAMEFORGE_SETTINGS.bat
- COLLECT_DEBUG_LOGS.bat
- UNINSTALL_GAMEFORGE.bat
- RUN_CODE_AUDIT.bat
- BUILD_REAL_WINDOWS_INSTALLER.bat

TEST WITHOUT INSTALLING:
Double-click START_GAMEFORGE_SAFE_DIAGNOSTIC.cmd.

TO GENERATE:
1. Paste your full game prompt into Dashboard → Describe the full game.
2. Keep:
   - Mode: Forge Full Game Draft
   - Game Size: Full Game Draft
   - Graphics Target: Realistic or Hyper-Realistic Target
   - Perspective: First Person
3. Click Autonomously Generate Playable Game.
