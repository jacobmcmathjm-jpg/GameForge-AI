# GameForge Asset Library

This folder is for downloaded or imported asset packs.

Recommended formats:
- 3D models: .glb / .gltf first, then .obj / .fbx later
- textures: .png / .jpg
- audio: .wav / .ogg / .mp3
- packs: .zip

Important: Only use packs you own or packs with a licence that allows your intended use.
